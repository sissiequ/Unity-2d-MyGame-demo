
# 2D Platformer Game

**Unity | C# | WebGL**

A 2D pixel-art platformer featuring character
movement, platform-based level design,
and a forest-themed environment.

## Play the Game

**[Play Online — WebGL Demo](https://sissiequ.github.io/game_demo.html)**

Play the game directly in your browser.
No installation required.

## Features

- 2D character movement and jumping
- Platform-based level design
- Pixel-art forest environment
- Camera-follow and world-scrolling systems
- Modular C# gameplay scripts

## Technologies

- Unity 2022.3
- C#
- Unity 2D Physics
- WebGL
- Git & GitHub

## Getting Started

1. Clone or download this repository.
2. Open the project using Unity Hub.
3. Use Unity 2022.3.62f3 or a compatible editor.
4. Open the game scene in the Unity Editor.
5. Press Play to run the game locally.
